# إعداد رابط الدخول السحري في Supabase

يرسل نموذج الإدارة رابط دخول سحريًا إلى عنوان المعاينة الحالي بدل `localhost`. لكي يقبل Supabase هذا العنوان، أضفه يدويًا إلى قائمة عناوين العودة المسموحة.

## خطوة واحدة مطلوبة الآن

افتح مشروع Supabase ثم انتقل إلى **Authentication → URL Configuration**. في **Redirect URLs** أضف هذا العنوان كاملًا:

```text
https://3000-igrycpt3pzscmeqwsre56-029d6cb6.us4.manus.computer/admin
```

احفظ التغيير، ثم افتح `/admin` في المعاينة واطلب رابط دخول جديدًا. لا تستخدم أي رابط قديم لأن صلاحية الرابط محدودة ولأنه قد يحتوي على بيانات جلسة.

## عند إطلاق النطاق

بعد ربط النطاق الحقيقي لاحقًا، أضف أيضًا:

```text
https://alshafra.com/admin
```

واجعل **Site URL** هو `https://alshafra.com` فقط عند مرحلة الإطلاق وبعد اختبار النطاق. لا تضع مفاتيح Supabase أو روابط دخول كاملة في المحادثات أو المستودع.
