# إعداد مفاتيح إشعارات المتصفح

تحتاج إشعارات المتصفح إلى زوج مفاتيح VAPID ثابت للموقع. احفظ المفتاح الخاص بسرية تامة ولا ترسله في الدردشة أو تضفه إلى Git.

إذا كان Node.js متاحًا لديك محليًا، شغّل الأمر التالي في جهازك:

```bash
npx web-push generate-vapid-keys
```

سينتج الأمر مفتاحًا عامًا ومفتاحًا خاصًا. أدخل القيمتين فقط في بطاقة الأسرار الآمنة التي تظهر داخل المشروع، وفق الحقول التالية:

| الحقل | القيمة |
|---|---|
| `VAPID_PUBLIC_KEY` | Public Key |
| `VAPID_PRIVATE_KEY` | Private Key |
| `VAPID_SUBJECT` | `mailto:runcode.company@gmail.com` |

لا تغيّر المفتاحين بعد ظهور اشتراكات حقيقية إلا مع خطة لإعادة اشتراك الزوار؛ إذ يرتبط الاشتراك بالمفتاح العام المستخدم وقت إنشائه.
