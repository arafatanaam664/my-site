# معايير قبول إطلاق Alshafra

| المجال | معيار القبول | الحالة الحالية |
|---|---|---|
| الهوية والمحتوى | لا يحمل الموقع الجديد هوية الموقع السابق، ولا تنشر صفحات بلا محتوى أصلي أو مصدر مناسب. | متحقق في الواجهة الأولية؛ نشر المحتوى من لوحة الإدارة قيد الإكمال. |
| الأدوات والتقويم | الأدوات تعمل محليًا، والتقويم يميّز بين التاريخ من جهاز المستخدم والمعلومات المرجعية. | متحقق. |
| SEO | HTML خادمي، canonical وOpen Graph وsitemap على `https://alshafra.com`، ومسارات البحث والإدارة noindex. | متحقق في بيئة التطوير؛ يلزم فحص الإنتاج بعد ربط النطاق. |
| انتقال المسارات | 301 للمسارات المتطابقة فقط و410 للمحتوى القديم الذي لا يملك بديلاً فعليًا. | متحقق برمجيًا؛ يلزم فحصه على الإنتاج. |
| إدارة المحتوى | إنشاء مسودة، سجل مراجعة، مصادر، اعتماد، نشر، ودور مستخدم مضبوط. | إنشاء المسودة وسجل المراجعة متحققان؛ بقية الخطوات قيد الإكمال. |
| التنبيهات | لا إنشاء اشتراك أو إرسال إلا بموافقة صريحة قابلة للسحب، ولا جدولة قبل النشر. | نموذج البيانات متحقق؛ القناة والإرسال قيد الإكمال. |
| الجودة | TypeScript وVitest وتدقيق الروابط العامة ناجحة، ومراجعة الجوال والسطح مكتملة. | متحقق جزئيًا؛ يلزم فحص أداء وإتاحة نهائيان. |

## خطوة النطاق

بعد اكتمال المحتوى والإدارة، يُنشأ checkpoint حديث، ثم ينشر مالك المشروع المنصة من واجهة الإدارة. بعد ذلك فقط يُربط `alshafra.com` بالمشروع المنشور ويُراجع `robots.txt` و`sitemap.xml` وcanonical والتحويلات من بيئة الإنتاج. لا يُحذف الموقع السابق قبل نجاح هذه الاختبارات.
