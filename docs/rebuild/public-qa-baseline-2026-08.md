# خط أساس تحقق الجودة العامة

**تاريخ التحقق:** 26 أغسطس 2026  
**النطاق:** معاينة Worker المحلية لمنصة Alshafra، وليس بيئة الإنتاج أو النطاق النهائي.

## ما تم التحقق منه

تمت مراجعة المسارات العامة التالية بصريًا في عرض هاتف بعرض 375 بكسل: الصفحة الرئيسية، كتالوج الأدوات، حاسبة التاريخ، الدليل المنشور عن تقويم أم القرى، تقويم أم القرى، وصفحة البحث لعبارة «تقويم». ظهر النص العربي وواجهات الإدخال وروابط التصفح وبطاقات المحتوى ضمن تدفق رأسي قابل للقراءة، من دون تراكب ظاهر أو قص أفقي في اللقطات.

| المسار | حالة العرض | الملاحظة |
|---|---:|---|
| `/` | مقبول | المسارات، الأدوات، الدعوة إلى الإشعارات، والتذييل تتدرج إلى الهاتف بوضوح. |
| `/tools` | مقبول | يعرض كتالوج الأدوات الفعلية فقط، ومنها حاسبة فرق الأيام والعمر والتاريخ. |
| `/tools/date-offset` | مقبول | الحقول وزر الحساب تنتقل إلى عمود واحد على الهاتف. |
| `/guides/umm-al-qura-calendar-guide` | مقبول | الدليل المنشور يعرض العنوان والغلاف والمحتوى والمصدر. |
| `/calendar/umm-al-qura` | مقبول | التاريخ والمصدر والتحديث يظهران بوضوح. |
| `/search?q=تقويم` | مقبول | النتيجة المنشورة تظهر ضمن بطاقة قابلة للقراءة. |

تم فحص استجابات HTTP المحلية للمسارات نفسها؛ جميعها أعادت الحالة `200`. تراوح زمن الاستجابة المحلي المسجل بين نحو 0.81 و1.96 ثانية، وهو قياس تطوير تقريبي لا يمثل أداء الإنتاج أو شبكة الزائر.

## الحراسة والإتاحة

أجري تعطيل مؤقت قابل للاستعادة لمفتاحي `tools_core` و`content_core`. عند تعطيلهما عادت فهارس الأدوات والأدلة ومسارات المادة بحالة `404`، واختفت روابطهما من الصفحة الرئيسية، ثم استعيدت حالتهما وعادت المسارات بحالة `200`. كما تحققت اللقطات من أن صفحات الحجب تعرض العربية داخل وثيقة HTML بترميز UTF-8 سليم.

## حدود هذا الخط الأساسي

هذا ليس قبول إطلاق نهائيًا. لا تزال اختبارات الإنتاج والنطاق النهائي وRedirect URLs ورابط الدخول السحري ومفاتيح VAPID ورسائل البريد الفعلية متطلبات تشغيلية مفتوحة. كذلك لا يثبت هذا الفحص سرعة الإنتاج أو مؤشرات Core Web Vitals أو التوافق مع كل قارئ شاشة أو كل متصفح. لا ينبغي تحويله إلى وعد بترتيب أو زيارات أو قبول في أي خدمة خارجية.
