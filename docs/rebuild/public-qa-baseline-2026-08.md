# خط أساس تحقق الجودة ومعايير قبول الإطلاق

**تاريخ التحديث:** 27 أغسطس 2026  
**النطاق:** معاينة Worker المحلية لمنصة Alshafra وبيانات النشر المرتبطة بها. لا يمثل هذا المستند بيئة إنتاج أو تحويلًا للنطاق النهائي.

## ملخص الحالة

تملك المنصة الآن أساسًا عامًا عربيًا متجاوبًا، ومسار محتوى موثقًا، وأدوات عملية تعمل داخل المتصفح، وبحثًا عربيًا، وتحليلات خصوصية اختيارية، ومشاركة عامة لا تنشر تلقائيًا. لا يعني ذلك قبول إطلاق عام؛ إذ تبقى مهام مرتبطة بالنطاق النهائي والبريد والإشعارات واختبارات الإنتاج الفعلية غير منجزة عمدًا.

> **قرار القبول الحالي:** النسخة مناسبة لمواصلة إدخال المحتوى والاختبار داخل المعاينة، وليست جاهزة بعد لتحويل نطاق `alshafra.com` أو فتح وحدات المجتمع أو تشغيل الإشعارات.

## ما تم التحقق منه

تحققت المراجعة المرئية على الهاتف من كتالوج الأدوات وأداة معرفة يوم الأسبوع، وعلى سطح المكتب من الصفحة الرئيسية والبحث والدليلين المنشورين. ظهرت النصوص العربية والتصميم المتجاوب وحقول الإدخال وروابط التنقل والتذييل ضمن تدفق قابل للقراءة، دون قص أفقي ظاهر في اللقطات. كما حُفظ رابط تخطٍ إلى المحتوى الرئيسي وحالة تركيز مرئية للعناصر التفاعلية، مع احترام تفضيل تقليل الحركة.

| المجال | الحالة المتحققة | الدليل التشغيلي |
|---|---|---|
| المحتوى المنشور | دليلان عربيان موثقان: تقويم أم القرى، وحساب تاريخ قبل أو بعد عدد من الأيام | كلا المسارين يعيدان `200`، ويظهر لكل مادة مصدر وصورة رئيسية وبيانات وصفية صادقة. |
| الأدوات | أربع أدوات فعلية: فرق الأيام، العمر، التاريخ قبل/بعد أيام، ويوم الأسبوع من تاريخ ميلادي | حسابات محلية مع تحقق من الإدخال، وقياس استخدام لا يعمل قبل موافقة الزائر. |
| البحث | نتائج للمحتوى المنشور ولتعريفات الأدوات المتاحة | صفحة النتائج `noindex`، ونتائج الأدوات تختفي عند تعطيل مفتاح الأدوات. |
| الوسائط | صور رئيسية مرتبطة بمحتوى منشور فقط | مسار الوسيط يفحص ارتباط الصورة بمادة منشورة قبل إتاحتها. |
| المحتوى الزمني | صفحة تقويم أم القرى تعتمد استجابة خادمية ومصدرًا معلنًا | لا تعتمد الصفحة على ساعة المتصفح وحدها، وتعرض حالة صريحة عند تعذر المصدر. |
| القياس | زيارات وقراءة واستخدام أدوات ومشاركات محتوى مجهّلة | لا تحفظ أسماء أو عناوين IP أو بصمات أجهزة، ولا يبدأ القياس دون موافقة صريحة. |
| المشاركة والتوزيع | مشاركة مستخدم اختيارية وصندوق نسخ يدوي إداري | لا توجد مفاتيح منصات أو اتصالات بمزودين أو إرسال أو جدولة تلقائية. |

## التحقق التقني

بعد آخر تحديثات الكود، اجتازت حزمة الاختبار الكاملة **106 اختبارات** ضمن **56 ملف اختبار**. أتم فحص Astro بلا أخطاء أو تحذيرات، مع تلميح قائم مسبقًا في نموذج احتياطي لإدارة المعاينة. كما أُنجز بناء Worker بنجاح. تؤكد اختبارات متخصصة أن حراسة `tools_core` تمنع مسار أداة يوم الأسبوع ونتائجها في البحث عند إيقاف المفتاح مؤقتًا، ثم تعيد ظهورها عند استعادة الحالة.

اختبر مسار الدليل الثاني والصورة المرتبطة به قراءةً فقط، وتحققت استجابة `200` ونوع الصورة. كذلك قُرئ تقرير التحليلات الإداري بجلسة تطوير محلية قصيرة ثم أغلقت الجلسة، وتأكد وجود حقل تفاعلات مشاركة المحتوى من دون تسجيل بيانات جديدة أو كشف أي قيمة حساسة.

## حالة الوحدات المقفلة

تبقى الوحدات غير الجاهزة غير مكشوفة للعامة من خلال مفاتيح إتاحة صريحة. المجتمع لا يملك مسارًا عامًا ولا يقبل إدخالات من زوار مجهولين. أسس طابور الإشراف موجودة داخل الإدارة، لكن فتح المجتمع مؤجل إلى أن تكتمل بنية الأعضاء ومكافحة الإساءة وحدود الاستخدام ومراجعة الجودة وسياسة الفهرسة.

| الوحدة أو المسار | الحالة الحالية | شرط التقدم |
|---|---|---|
| إشعارات المتصفح | واجهة اشتراك موجودة لكن غير مفعلة | إدخال قيم VAPID الآمنة عبر حقول الإدخال المحمية ثم اختبار الاشتراك والإلغاء في البيئة النهائية. |
| الدخول السحري | الواجهة ورسائل الخطأ موجودة | اختبار بريد فعلي بعد ضبط Redirect URLs وموفر البريد وحد الإرسال في Supabase. |
| المجتمع | مقفل وغير مفهرس | آليات عضوية، حماية من الرسائل المزعجة، حدود طلبات، مراجعة تحريرية، واختبارات فتح تدريجي. |
| النشر الاجتماعي | يدوي فقط | موافقة صريحة مستقبلية على مزود رسمي ومفاتيح وآلية تشغيل قبل أي اتصال خارجي. |
| الأتمتة والجدولة | غير مفعلة | اختيار مسار التشغيل ومتطلبات الأمان ومصدر الأحداث ووجهة النتائج قبل كتابة أي مشغل. |

## معايير قبول الإطلاق المتبقية

لا يُنصح بالإطلاق أو تحويل النطاق قبل استكمال المتطلبات التالية. هذه معايير تشغيلية وليست وعودًا بنتائج بحث أو زيارات أو إيرادات.

| الأولوية | معيار القبول | ما يلزم إثباته قبل اعتباره مكتملًا |
|---|---|---|
| حرجة | النطاق النهائي | ربط `alshafra.com` بموافقة المالك، وضبط canonical وOpen Graph وsitemap وrobots على الأصل النهائي، وفحص الاستجابات من النطاق نفسه. |
| حرجة | أمن الإدارة | تعطيل وصول التطوير المؤقت في بيئة الإنتاج، واختبار دور محرر حقيقي ومسار خروج وجلسة منتهية الصلاحية. |
| حرجة | الدخول بالبريد | نجاح رسالة دخول واحدة إلى البريد المعتمد ومسار العودة النهائي من دون إعادة توجيه إلى localhost. |
| عالية | الإشعارات | مفاتيح VAPID آمنة، وموافقة واضحة، وإلغاء اشتراك صالح، واختبار تسليم فعلي لمشترك اختار الخدمة. |
| عالية | الأداء والإتاحة | قياس إنتاجي لـ Core Web Vitals، ومراجعة قارئ شاشة ولوحة مفاتيح، وفحص متصفحات هاتف وسطح مكتب فعلية. |
| عالية | المحتوى | استمرار النشر بمصادر وصور ونصوص أصلية ذات فائدة قبل توسيع الواجهات أو فتح أقسام جديدة. |
| مشروطة | المجتمع أو الأتمتة | موافقة صريحة على نطاق كل وحدة بعد اكتمال ضوابطها، مع إبقاء أي واجهة غير مكتملة مخفية. |

## حدود القياس والادعاءات

سرعة المعاينة المحلية لا تقيس تجربة شبكة الزائر أو أداء الإنتاج. كما أن صلاحية البيانات المنظمة، وتحسين النص والصورة، ووجود مصادر موثقة، قد تساعد في فهم المحتوى وفهرسته لكن لا تضمن ترتيبًا أو ظهورًا في الاقتراحات أو نتائج ذكاء اصطناعي أو قبولًا إعلانيًا أو عدد زيارات أو عائدًا. لا يوجد في النسخة أي نشر اجتماعي تلقائي أو حملة آلية أو ادعاء بمؤشرات غير مسجلة فعليًا.
