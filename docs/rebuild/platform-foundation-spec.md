# مواصفة طبقات Alshafra المشتركة

هذه المواصفة تنفذ قرار المنصة المعتمد: بناء طبقات مشتركة قابلة للتوسع، مع إبقاء الميزات غير الجاهزة غير مرئية وغير قابلة للاستخدام حتى تجتاز معايير القبول.

## الوحدات المشتركة

| الوحدة | مسؤوليتها | ما لا تفعله |
|---|---|---|
| أنواع المحتوى | تعريف الأنواع الممكنة وعرضها العام عند تفعيلها. | لا تخلق مسارًا أو نموذج نشر لنوع لا تملك واجهة وقواعد جودة. |
| التصنيفات والوسوم | تنظيم المحتوى وإتاحة علاقات قابلة للبحث والربط. | لا تفهرس صفحات فارغة أو تصنيفات بلا مواد منشورة. |
| الكيانات | ربط المحتوى بخدمة أو تطبيق أو جهة أو موضوع متكرر. | لا تستخرج أو تنشئ كيانات تلقائيًا بلا مراجعة. |
| مفاتيح الميزات | تحديد إتاحة وحدة للجمهور مع سجل تدقيق. | لا تمنح صلاحيات مستخدم أو تتجاوز RLS. |
| سجل الأحداث | تسجيل أحداث النطاق التشغيلي بعد حدوثها بنجاح. | لا يحل محل طابور مهام أو يسمح بإرسال خارجي متزامن. |

## تفعيل آمن

الميزة لا تفعّل إلا إذا اكتملت بياناتها وواجهتها وصلاحياتها واختباراتها وقواعد SEO والأمان الخاصة بها. القيمة الافتراضية للمجتمع، الحسابات العامة، الفرص، الأتمتة، والنشر الاجتماعي هي **موقوفة**. لا يترتب على تسجيل مفتاح للميزة إنشاء زر ظاهر أو API عام تلقائيًا.

## أحداث المنصة

يسجل `platform_events` حقيقة منتهية، مثل `content.published`. في مراحل لاحقة يقرأ outbox متين هذه الأحداث لإنشاء jobs مستقلة. لا يجوز تنفيذ اتصال اجتماعي أو بريد أو عملية دورية داخل طلب نشر المحتوى نفسه.
