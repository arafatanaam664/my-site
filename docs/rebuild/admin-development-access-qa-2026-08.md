# تحقق جلسة التطوير ولوحة الإدارة

**تاريخ التحقق:** 26 أغسطس 2026  
**البيئة:** معاينة Worker المحلية فقط.

تم فتح جلسة تطوير مؤقتة عبر نقطة الإدارة باستخدام الرمز المحفوظ في البيئة، من دون طباعته أو تخزينه في الملفات أو السجلات. أعادت نقطة فتح الجلسة وصفحة `/admin` حالة `200`، ثم أعادت مسارات القراءة التالية الحالة `200`: المحتوى، التحليلات، مفاتيح الميزات، إعدادات المنصة، التوزيع اليدوي، وطابور إشراف المجتمع. لا ينفذ هذا التحقق أي طلب إنشاء أو تعديل أو نشر.

| عنصر التحقق | النتيجة |
|---|---|
| فتح جلسة تطوير مقيدة بالمضيف المحلي | ناجح |
| صفحة الإدارة ومسارات القراءة المحمية | ناجحة |
| ترويسة الخروج | تُرجع كوكيًا فارغًا مع `Max-Age=0` لمسح جلسة التطوير |
| نطاق الإنتاج `alshafra.com` | لا يقبل رمز التطوير بحسب الاختبار القائم |

يظل التحقق المرئي الموثق لرحلة محرر كاملة، بما يشمل إنشاء مسودة ومراجعتها ونشرها على الهاتف وسطح المكتب، متطلبًا منفصلًا. كذلك لا يصبح هذا المسار بديلًا عن Supabase Auth في الإطلاق؛ يجب تقاعد رمز وصول التطوير قبل ربط النطاق النهائي.
